📊 Smart Attendance & Performance Tracker

A Java Console Application to track attendance and performance

📌 Project Overview

This project calculates attendance percentage, average marks, and determines exam eligibility based on given criteria.

📌 Features

  • ✔ Attendance Percentage Calculation
  • ✔ Average Marks Calculation
  • ✔ Exam Eligibility Check
  • ✔ Warning for Low Attendance

📊 Eligibility Criteria

✔ Minimum 75% Attendance
✔ Minimum 40% Average Marks

🛠 Technologies Used

Java | Scanner | Loops | If-Else
