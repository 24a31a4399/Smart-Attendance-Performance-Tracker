# Smart Attendance & Performance Tracker

This is a Java console application that calculates:

- Attendance Percentage
- Average Marks
- Exam Eligibility

## Features
- Calculates attendance percentage
- Displays warning for low attendance
- Calculates internal marks average
- Checks eligibility (75% attendance & 40% average)
- Clean formatted output (2 decimal places)

## Technologies Used
- Java
- Scanner
- Loops
- If-Else Conditions
